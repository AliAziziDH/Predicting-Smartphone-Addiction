### 1. Fail-Closed Google Drive Mount via FUSE-T (Launchd Daemon)
Save this configuration as `/Users/out/Library/LaunchAgents/com.ali.gdrive.mount.plist`. It automatically mounts your 5TB Google Drive on boot using FUSE-T and rclone, ignoring Apple Double/DS_Store metadata to maximize virtual disk speed.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.ali.gdrive.mount</string>
    <key>ProgramArguments</key>
    <array>
        <string>/opt/homebrew/bin/rclone</string>
        <string>mount</string>
        <string>ali-rclone-drive:</string>
        <string>/Users/out/gdrive</string>
        <string>--vfs-cache-mode</string>
        <string>full</string>
        <string>--dir-cache-time</string>
        <string>5m0s</string>
        <string>--noappledouble</string>
        <string>--noapplexattr</string>
        <string>--volname</string>
        <string>Ali5TBDrive</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/Users/out/Library/Logs/com.ali.gdrive.mount.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/out/Library/Logs/com.ali.gdrive.mount.err</string>
</dict>
</plist>
```

Command to load the daemon:
$ launchctl load -w ~/Library/LaunchAgents/com.ali.gdrive.mount.plist

### 2. Secure Nightly Sync Script with Fail-Closed Proxy Protection
Save this script as `/Users/out/Desktop/gdrive_nightly_sync.sh` and make it executable (`chmod +x`). It uses Netcat to check if your Streisand proxy on port 10809 is active. If offline, it triggers a Fail-Closed abort to protect your real IP from leaking to GCP.

```bash
#!/bin/zsh
# com.ali.gdrive_nightly_sync.sh
# Mapped to Streisand proxy on Port 10809 (Fail-Closed)

SRC_DIR="/Users/out/Desktop/To-Upload"
ERR_FILE="/Users/out/Desktop/To-Upload/SYNC_FAILED.txt"
LOG_FILE="/Users/out/Library/Logs/gdrive_nightly_sync.log"
PROXY_PORT=10809

# Pre-flight check: Verify proxy port is active
nc -zv -w 5 127.0.0.1 $PROXY_PORT &>/dev/null

if [ $? -ne 0 ]; then
    # FAIL-CLOSED Triggered
    echo "❌ [$(date)] Proxy on port $PROXY_PORT is offline! Aborting sync." >> $LOG_FILE
    echo -e "❌ همگام‌سازی شبانه ناموفق بود!\n\nعلت خطا: فیلترشکن (Streisand) روی پورت ۱۰۸۰۹ خاموش یا غیرفعال بود.\nسپر امنیتی Fail-Closed برای جلوگیری از لو رفتن آی‌پی واقعی شما به گوگل‌کلاد فعال شد و عملیات انتقال فایل‌ها را متوقف کرد.\n\nزمان تلاش: $(date)" > $ERR_FILE
    exit 1
fi

# SUCCESS CASE: Clear old errors, keep system awake and run sync
rm -f $ERR_FILE
adrafinil-start # Keep system awake during heavy cloud IO

export http_proxy="http://127.0.0.1:$PROXY_PORT"
export https_proxy="http://127.0.0.1:$PROXY_PORT"

rclone move "$SRC_DIR" "ali-rclone-drive:Backups/Nightly" --log-file="$LOG_FILE" --log-level=INFO

# Re-enable system sleep on completion
adrafinil-stop
osascript -e 'tell application "System Events" to sleep'
```

SECTION 3: GOOGLE AGENTS CLI (google-agents-cli) LOCAL COMPONENT
------------------------------------------------------------------------
The google-agents-cli is the programmatic backbone for your Agentic SDLC (A-SDLC). It allows your local workspace to scaffold, run, evaluate, and deploy production-style agents natively on Google Cloud.

### 1. Environment Setup & Project Initialization
Run these commands to set up the CLI using python-uv (or uvx) and initialize your local agent:

```bash
# Install CLI and activate skills
pip install google-agents-cli uv
agents-cli setup

# Initialize a standard Agentic Project with Agent Identity

# Standard Agent Project Layout generated:
#  AGENT_PROJECT/
#  ├── AGENT_NAME/                # Main agent logic (adk-based)
#  │   ├── agent.py               
#  │   └── fast_api_app.py        
#  ├── .agent_engine_config.json  # Enforces { "identity_type": "AGENT_IDENTITY" }

#  └── pyproject.toml             # Project dependencies
```
